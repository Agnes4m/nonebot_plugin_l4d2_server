# 内置敏感词库

来自 [konsheng/Sensitive-lexicon](https://github.com/konsheng/Sensitive-lexicon)（MIT 协议，见同目录 `LICENSE`），取自提交 `d967c30b053fa40b06c5a0dddf0be493f2dfae46`（2026-08-17）的 `Vocabulary/` 目录。

默认不启用，在 `.env` 里设 `L4_BLOCK_BUILTIN_WORDS=true` 打开。命中的词在服务器名、玩家名里替换成 `*`，服务器和玩家照常显示。

## 收录的分类

政治类型、反动词库、暴恐词库、涉枪涉爆、色情类型、贪腐词库、其他词库、新思想启蒙，去重后约 2100 个词（少于 2 个字的不加载）。

与原文件的差异：去掉行尾空白、统一以换行结尾，并删掉下面这些和 L4D2 游戏用语、常见昵称或人名冲突的词：

| 分类 | 删掉的词 |
|---|---|
| 政治类型 | 江哥、胡总、国峰、国锋 |
| 反动词库 | 集合、清真 |
| 暴恐词库 | 枪手、盘古 |
| 涉枪涉爆 | 燃烧弹 |
| 色情类型 | 调教 |
| 贪腐词库 | 自杀、双开、陈忠 |

## 没有收录的分类

- GFW补充词库、零时-Tencent、网易前端过滤敏感词库：包含手枪、冲锋枪、猎枪、炸弹、电击器、燃烧瓶、嗑药、服务器等 L4D2 常用词。
- 民生词库、补充词库、COVID-19词库、色情词库、广告类型：混有大量常用词，如大师、复制、车库、北京、武汉、刺激、兼职、网络。
- 非法网址：都是域名，和服务器名、玩家名关系不大。

需要的话可以自行下载，放到 `<data_dir>/block_words/`（每行一个词），发 `l4刷新` 生效。想去掉内置词库里的某个词，可以关掉内置词库，把本目录的文件复制到 `<data_dir>/block_words/` 再改。

## 更新

下载新版对应分类文件覆盖本目录，再按上面的差异处理一遍。
